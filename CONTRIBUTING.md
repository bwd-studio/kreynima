# Contributing

Open an issue describing the user problem before a large change. Use a focused feature branch and a pull request; explain behavior, tests, and limitations in plain English. Do not commit credentials, build output, or unrelated edits. Preserve history and user work.

Run `npm ci` and `npm run check`. For desktop changes also run the native checks in [building.md](docs/building.md). Report checks you could not execute. Add meaningful tests for behavior or boundary changes. Follow [AGENTS.md](AGENTS.md), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), and the architecture documents.

Contributions to program code and documentation are accepted under GPL-3.0-only, with existing third-party notices preserved. Submit only material you have permission to contribute. No copyright assignment or CLA is required by this policy. Separately licensed artwork must have explicit provenance and a license file; discuss official brand changes first.

Maintainers review scope, security, accessibility, licensing, and test results before merging. CODEOWNERS names the verified repository administrator, @BuildWithDani. Expand ownership to eligible teams as the project grows. Contributors do not need paid services.
