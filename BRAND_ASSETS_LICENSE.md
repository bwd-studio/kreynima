# Brand assets — classification policy requiring legal review

BUILD 000 introduces no logo, mascot, font, or separate brand artwork. The plain solid-color development window icon is a GPL-covered program asset, not official brand artwork. Plain text names in program source, documentation, and the development UI remain covered by the program's GPL-3.0-only license. Do not infer a proprietary artwork exception for those files.

Future standalone promotional brand artwork must live outside runtime program assets (for example, `brand/`) with an explicit per-file license, author, provenance, and classification reviewed before inclusion. This document grants no new artwork license and does not retroactively relicense any file. Do not include artwork with unclear rights.

Assets required to build, modify, or run the GPL-covered program must remain available under GPL-compatible terms with corresponding source. Trademark guidance cannot restrict GPL freedoms in such assets. A restrictive promotional artwork license must never silently apply to runtime assets. See [TRADEMARKS.md](TRADEMARKS.md) for source-identification guidance. Counsel should review future asset licenses and this boundary before release.
